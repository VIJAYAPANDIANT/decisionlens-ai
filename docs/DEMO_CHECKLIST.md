# Demo Checklist

## PRE-DEMO
- [ ] Backend running (`uvicorn app.main:app --port 8000`) or deployed
- [ ] Frontend running (`npm run dev`) or deployed
- [ ] Gemini API key configured in backend `.env`
- [ ] Sample CSV (`sample-data/sales_data.csv`) available on local machine
- [ ] Browser opened to correct URL (e.g., http://localhost:5173)
- [ ] No console errors visible
- [ ] Internet connection available (for Gemini API calls)
- [ ] Correct deployed URL confirmed (if doing a live cloud demo)

## DEMO
- [ ] Upload CSV
- [ ] Show KPIs
- [ ] Show chart
- [ ] Show insight
- [ ] Open evidence
- [ ] Ask AI question
- [ ] Show recommendation
- [ ] Open What-If Simulator
- [ ] Select +10%
- [ ] Show deterministic calculation

## POST-DEMO
- [ ] Stop screen recording
- [ ] Verify video length (Ensure it is under the 3-minute limit)
- [ ] Verify GitHub repository is public and updated
- [ ] Verify README is complete
- [ ] Verify deployment URL is accessible
- [ ] Verify submission files and Devfolio/submission form
