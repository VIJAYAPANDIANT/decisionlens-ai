# Video Recording Checklist

- [ ] Browser zoom around 90–100% (Ensure all UI fits beautifully without horizontal scrolling)
- [ ] Close unnecessary tabs
- [ ] Hide personal information (Bookmarks bar, extensions, etc.)
- [ ] Use a clean browser window
- [ ] Ensure application is already loaded and backend is running successfully
- [ ] Keep sample CSV ready on Desktop or a quick-access folder
- [ ] Keep demo question ready to copy-paste (from `DEMO_QUESTIONS.md`)
- [ ] Disable distracting notifications (Do Not Disturb mode on OS)
- [ ] Test microphone if narration is used
- [ ] Keep recording under the hackathon limit (3 Minutes)
- [ ] Use the exact demo flow outlined in `DEMO_SCRIPT.md`
